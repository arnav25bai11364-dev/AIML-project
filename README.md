AI Rock Paper Scissors 🎮🤖

=======================================================

An interactive Rock-Paper-Scissors game powered by an adaptive AI 🤖✨  
Built using Python 🐍 and CustomTkinter, this project shows how simple AI can create a smart and engaging game experience.

--------------------------------------------------

1. Overview 📌

- Play Rock, Paper, Scissors against an intelligent AI 🎮  
- AI learns from your moves and adapts over time 🧠  
- Combines machine learning basics with a GUI interface 💻  

--------------------------------------------------

2. Key Features 🚀

- Interactive and modern GUI using CustomTkinter 🖥️  
- Dark mode interface 🌙  
- Smart AI opponent 🤖  
- Real-time results display ⚡  
- Smooth and lightweight performance  

--------------------------------------------------

3. How the AI Works 🧠

Pattern Recognition 🔍  
- Tracks your previous moves  
- Predicts your next move based on patterns  

Frequency Analysis 📊  
- Counts how often you play each move  
- Uses the most frequent move for prediction  

Decision Strategy 🎯  
- 80% chance to counter your move correctly  
- 20% chance to play randomly for unpredictability 🎲
